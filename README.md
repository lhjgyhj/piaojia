# 票夹（Piaojia）

面向小团队的数电发票归集与报销查重系统。上传或转发 PDF、OFD、XML 发票，自动解析、查重、走报销审批，财务按模板导出。

## 为什么做这个

- 数电票自 2024 年 12 月起全国推广，同一张发票有 PDF、OFD、XML 三种文件，很多小团队的财务仍在逐张打开、手工整理。
- 数电票可以重复下载，纸质时代"原件只报一次"的约束不存在了，小团队缺少内部查重手段。
- 现有产品（票管大师、发票盒子）功能完整但收费且数据存在对方服务器；钉钉、飞书审批没有发票解析和查重。

定位是给没有财务系统的小团队，在内部报销环节做查重和流程管理。税务数字账户的"入账标识"解决的是入账环节，解决不了"这张票在我们公司有没有人报过"。

## 计划功能

- 解析 PDF、OFD、XML 三种格式，提取发票号码、金额、税额、销售方、购买方
- 按发票号码查重，并发提交也不会重复入库
- 报销审批流：草稿、待审批、已通过、已报销，每次状态变化写审计日志
- 专属收票邮箱：转发邮件即可入库，不需要交出自己的邮箱授权码
- 导出 Excel 明细和合并 PDF

## 明确不做

不查验发票真伪（不访问税务总局查验平台），不做 OCR，不收费。

## 技术栈

Django 5.2 LTS · Celery · PostgreSQL · Redis · HTMX · Tailwind CSS · Docker
